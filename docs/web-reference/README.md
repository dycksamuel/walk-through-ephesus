# World English Bible reference text

These files hold the World English Bible (WEB, public domain) text of Ephesians and Acts 18–20, one entry per verse. The content checker (`tools/check-content.mjs`) compares every Scripture quotation in `/content` against them, so a typo in a quoted verse is caught before the game is published.

Source: the JSON edition of the WEB at https://github.com/TehShrike/world-english-bible, which is generated from the official text at https://ebible.org/web/. Footnotes are not included. The WEB is revised from time to time, so wording here may differ in small ways from the newest edition on ebible.org.

Do not edit these files by hand.
